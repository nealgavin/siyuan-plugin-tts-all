# Siyuan text to speech（全平台版）

支持 **桌面端、手机、平板（Pad）与鸿蒙版思源笔记**（含华为 Pura / Mate 系列）以及浏览器 / Docker 自部署。

插件内置**多引擎自动降级**：某个引擎不可用时自动切换到下一个，移动端与桌面端使用同一套功能。

> **来源与致谢**：本项目基于 [zuoez02/siyuan-plugin-tts](https://github.com/zuoez02/siyuan-plugin-tts)（MIT）二次开发，在原插件基础上补齐了手机 / 平板 / 鸿蒙端适配与多引擎降级。原项目版权归 zuoez02 及贡献者所有，详见 [LICENSE](LICENSE)。

## 安装

- **集市安装**：思源笔记 →「设置 → 集市 → 插件」，搜索「文本朗读（全平台）」，下载并启用。
- **手动安装**：从本仓库 [Releases](https://github.com/nealgavin/siyuan-plugin-tts-all/releases) 下载 `package.zip`，思源「设置 → 集市 → 已下载 → 安装包安装」。
- **从旧版升级**：本插件与原「文本朗读」是两个独立包，可同时安装；确认新版正常后，在集市「已下载」中卸载旧版即可，朗读设置需重新选择一次声源。

## 语音引擎

| 优先级 | 引擎 | 适用平台 | 说明 |
| --- | --- | --- | --- |
| 1 | **Edge 直连** | 桌面端 | 使用 Node 原生网络栈直连微软语音服务，可自定义请求头，音质最好、声源最多 |
| 2 | **Edge 经内核代理** | 全平台（内核 ≥ 3.7.0） | 由思源内核转发 WebSocket 连接并代发请求头，绕开浏览器禁止修改 `User-Agent` 的限制 |
| 3 | **在线语音（HTTP 备用）** | 全平台（内核 ≥ 3.1.28） | 经内核 `/api/network/forwardProxy` 拉取在线 TTS 音频，不依赖浏览器网络限制 |
| 4 | **系统语音（离线）** | 全平台 | 调用设备自带 TTS（Web Speech API），无需联网，作为最终兜底 |

> **关于移动端的说明**：微软 Edge 语音服务会校验请求中的 `User-Agent` 是否包含 `Edg/` 标记，而浏览器的 `User-Agent` 属于禁止脚本修改的请求头。因此移动端、平板与鸿蒙端**不能直接连接** Edge 服务，插件改为经由**思源内核代理**转发（内核由 Go 发起连接，可代发所需请求头）。若内核对 WebSocket 代理的支持不可用（低于 3.7.0），会自动降级到 HTTP 备用引擎。

在顶部栏菜单 →「语音引擎」中可查看当前生效的引擎，也可手动指定（默认为「自动」）。

## 使用方法

1. **朗读**：选中单个或多个块，点击块左侧块菜单 →「插件 → 文本朗读」；也可在文档标题菜单中朗读整篇文档。
2. **从当前块读到末尾**：块菜单 →「文本朗读（从当前块到末尾）」。
3. **朗读选中文字**：命令面板执行「朗读当前选中内容」（默认快捷键 `⌥⌘W`，桌面端）。
4. **停止 / 暂停 / 继续**：桌面端点击右下角状态栏的朗读按钮；手机、平板与鸿蒙端使用屏幕下方的**悬浮控制条**（移动端前端不显示状态栏，故提供悬浮条）。
5. **切换人声（声源）**：在播放悬浮条或状态栏上**点击声源标签**，直接弹出完整声源列表选择（手机端以底部面板呈现）。播放速率与语音引擎在顶部栏朗读图标菜单中设置。
6. **定位当前朗读块**：点击状态栏文字或悬浮控制条中的文字，即可滚动到正在朗读的块。
7. **从任意块开始朗读**：播放中双击 / 双击轻点某个块，即从该块开始朗读到文档末尾。

## 平台适配说明

- **桌面端（Windows / macOS / Linux）**：底部状态栏显示朗读状态，支持快捷键。
- **手机 / 平板（Android / iOS）**：顶部栏图标位于「更多」面板，使用悬浮控制条控制播放。
- **鸿蒙版思源笔记（HarmonyOS）**：与移动端一致，通过内核代理连接语音服务。
- **浏览器 / Docker**：自动携带 API Token 访问内核接口。

朗读过程中当前块会有边框高亮；若某个块合成失败会被自动跳过，不影响后续内容。

## Changelog 变更记录

v1.2.4 - **修正切换人声偶发失败 + 切换后立即生效**

- **修正「切换人声后偶发报系统语音播放失败」**：切换声源时，`MsEdgeTTS.setMetadata()` 会 `close()` 掉已经建立且在途的合成请求，这个 rejection 被引擎调度层当成「Edge 引擎故障」，把 `edge-proxy` 标记为失败并**永久跳过**。此后朗读一路降级，最终落到系统语音；系统语音一旦不可用，就报出「系统语音播放失败」。现在切换声源会递增「声源代次」，在途请求的失败被识别为**预期中断**而非引擎故障：不拉黑引擎、不改用降级引擎，而是自动用新声源重试（最多 3 次）。
- **切换声源时主动断开旧连接**：只递增代次还不够 —— 旧请求要等很久才会超时，表现为「切了人声没反应」。现在切换时主动 `close()` 掉 Edge 连接，让在途请求立刻失败并在新声源下重试。
- **切换声源清空历史失败标记**：声源切换属于用户主动操作，视为一次干净的重试，避免此前某次网络抖动留下的失败标记导致 Edge 被永久跳过。
- **修正系统语音把「主动停止」误报为失败**：我们自己调用 `speechSynthesis.cancel()`（切换声源、换块、停止朗读）时，部分 WebView 会以 `interrupted`/`canceled` 之外的 reason 回调 `onerror`，此前会误报「系统语音播放失败」。现在主动取消过的朗读不再上报错误，真实故障仍然抛错。
- **切换人声立即生效**：此前切换后要等当前段读完才听到新声音，长段落会让人以为没生效。现在切换会**用新声源从当前块重新朗读**（保持「当前块 → 文档末尾」的范围，不重读已读过的内容）；未播放时只记住设置，不会突然开口；已停止的朗读不会被唤醒。

v1.2.3 - **修正连续双击块时声音重叠、悬浮窗偶发不显示**

- **修正「连续双击不同块会出现多路声音」**：`Controller.stop()` 末尾调用了 `init()`，而 `init()` 会把 `stopped` 重置回 `false`，于是被 `stop()` 打断、正卡在 `await` 里的旧播放循环会「复活」继续朗读；同时 `Player.stop()` 执行时当前 `AudioBufferSourceNode` 尚未创建（仍在等待音频上下文就绪），导致旧音频随后照样 `start()` 出声。连续双击几个块就会有几路声音叠在一起。现在 `stop()` 保留 `stopped = true` 终态、`await` 之后再次校验、并在 `start()` 前复查停止标志，旧朗读被彻底放弃。
- **修正「双击其它块时悬浮窗有时不出现」**：被取代的旧朗读播放到最后会调用 `hideControlBar()`，把**新**朗读刚显示出来的悬浮条一起关掉。现在悬浮条按「当前朗读」归属判断，旧朗读收尾不会影响新朗读的显示。
- **修正停止时可能卡住**：`AudioBufferSourceNode.stop()` 在部分 WebView（含鸿蒙 ArkWeb）不会再触发 `ended` 事件，会让播放链永久悬挂。现在停止时主动放行等待。
- **人声切换改为点击直接出列表**：点击悬浮条 / 状态栏上的声源标签，直接弹出**完整声源列表**供选择（手机端为底部面板），不再是「单击轮换、长按才出列表」，选择结果即时生效并提示。
- 不再在停止朗读时关闭共享的语音服务实例（此前会把下一段朗读正要复用的 Edge 连接一起拆掉）。

v1.2.2 - **双击跳转朗读 + 悬浮窗切换人声**

- **双击块从该块开始朗读**：播放（含暂停）状态下，双击/双击轻点任意块，即从该块开始朗读到文档末尾。为避免与思源自身的「双击选词 / 进入编辑」冲突，该手势**仅在播放中生效**，未播放时完全不拦截。若目标块已在当前播放列表中会直接复用，不再请求网络；滑动翻页不会被误判为双击。代码块不参与朗读。
- **悬浮窗直接切换人声**：移动端悬浮条与桌面端状态栏都新增声源标签，点击即可切换声源（v1.2.3 起改为点击直接弹出完整列表）。
- 声源扩充到 10 个（含晓伊、云健、辽宁小北、陕西小妮、台湾曉臻、粤语曉曼等）。
- 修正插件重载后事件监听重复绑定的问题（一次双击会触发多次朗读）。
- 语种不匹配时不再静默跳过：例如用「Connor 英文男声」朗读中文，Edge 会返回 0 字节，现在会自动降级到其它可用引擎，并给出可读提示。

v1.2.1 - **修正手机端/鸿蒙端「没有声音」**

- **修正播放无声的根因**：Edge 引擎返回的是裸 `ArrayBuffer`，与播放层约定的 `{ kind, data }` 不一致，导致解码结果取不到、`source.buffer` 为 `undefined`，播放时完全静音且不报错。现已在引擎调度层统一包装。
- **修正移动端自动播放策略拦截**：手机 / 鸿蒙 WebView 要求音频必须由用户手势触发。合成需要等待网络，等音频就绪时手势已失效，`AudioContext` 会停在 `suspended`，`source.start()` 不报错但没有声音。现在在所有点击入口（右键菜单、标题菜单、悬浮控制条、快捷键）的同步阶段先解锁音频，并在播放时确认上下文已进入 `running`。
- **修正百度在线语音不可用**：百度只接受 `rate ∈ {0,1,2,3,4,8,16,24,32}`，传文档常见的默认值 `5` 会返回 `aue and rate not match`。现已不再传该参数，语速统一交给播放层控制；分块降为 60 字以避开限流，单段失败自动重试，中途限流会自动切换服务商。
- 新增**环境自检**菜单（右键菜单 →「环境自检」），在无法连调试器的手机上直接显示：平台/内核版本、API 令牌、内核代理能力、`AudioContext` 状态、系统语音音色数、各在线引擎实测连通性，并给出针对性建议。
- **失败不再静默**：第一块朗读失败会直接弹出具体原因，解码失败 / 返回空音频 / 返回格式错误都会明确报错。
- 系统语音增加启动与播放超时，避免在未安装语音引擎的设备上无限等待。
- **避免把思源自身锁死**：思源内核会按 IP 统计「认证失败次数」，超过 5 次后指数退避锁定（最长 15 分钟），且锁定期间**正确的令牌也会被拒绝，每次重试还会延长锁定**，会连带影响思源界面。现在遇到 429 会立即停止重试、不再改用其它服务商重复尝试，并提示检查 API 令牌；无令牌时不会发送空的 `Authorization` 头，而是依赖同源会话 Cookie 完成鉴权。

v1.2.0 - **全平台支持**

- 适配 Pad、手机与鸿蒙版思源笔记（含华为 Pura / Mate 系列），并声明 `backends` / `frontends` 兼容性。
- 新增多引擎自动降级：Edge 直连 → Edge 内核代理 → HTTP 在线语音 → 系统离线语音。
- 移动端新增悬浮播放控制条（播放/暂停/停止/定位），解决移动端前端不挂载状态栏的问题。
- 音频格式改为 MP3，兼容 iOS / Android / 鸿蒙 WebView 的 `decodeAudioData`。
- 不再依赖 Node 专属 API：`crypto`、`net`、`tls`、`stream`、`Buffer` 均按平台降级处理，移动端不再加载失败。
- 修正纯 JS SHA-256 的字节序问题，并作为 `crypto.subtle` 不可用时的兜底。
- 播放使用全局共享 `AudioContext`，避免多块缓存导致上下文数量超限。
- SSML 文本增加 XML 转义，含 `&`、`<`、`>` 的内容不再朗读失败。
- 单个块合成失败自动跳过，不再中断整篇朗读。
